# RuView

RuView transforms ambient WiFi radio signals into a camera-free spatial radar that tracks human movement through walls and monitors vital signs. Learn how to deploy the high-performance Rust sensing engine and interactive visualizer with Docker Compose.

## Quick start

```sh

docker compose up -d
```
