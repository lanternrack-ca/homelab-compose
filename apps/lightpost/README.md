# LightPost, a One-Dashboard Social Media Scheduler,

LightPost lets you write a post once and send it to Bluesky, Mastodon, X, Threads, LinkedIn and more from your own server. Here is the recorded Docker Compose install of LightPost v0.2.0, running locally with no login and no Dockerfile.

## Quick start

```sh
cp .env.example .env     # then edit: change every change-me value
docker compose up -d
```
