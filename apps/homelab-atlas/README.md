# Homelab Atlas

Homelab Atlas is a free, MIT-licensed, self-hosted app that lays out homelab diagrams for you and exports them as PNG or SVG. This guide runs the official v0.12.0 release with one Compose file, then walks through the editor, the export privacy filter and the discovery wizard.

```sh
cp .env.example .env     # then edit: change every change-me value
docker compose up -d
```
